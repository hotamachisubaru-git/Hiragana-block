# 実機での確認

新しいテスト用ワールドで、Minecraftバージョン・ローダーバージョン・JARのコミットを記録します。

1. クリエイティブまたは `/hb give` から「あ・で・ぶ・ゃ・ん」を3色ずつ入手する。
2. 床・壁・空中に置き、6面の文字が読めることを確認する。Paperではチャンク境界（X/Zが15→16、-1→0）も確認する。
3. `あいう` を黒で並べ、`/hb answer あいう` と列の `/hb check` ですべて緑になることを確認する。
4. `うあい` はすべて黄、`あああ` は緑・黒・黒、`ううう` は黒・黒・緑になることを確認する。
5. 間に通常ブロックがある列で判定し、列の一部だけ色が変わらないことを確認する。
6. サバイバルで破壊し、同じ文字と色のアイテムが1個だけ落ちることを確認する。
7. チャンクを離れて戻り、再起動し、文字・色・答えが復元されることを確認する。
8. Paperはピストン・爆発・保護プラグインによる設置/破壊のキャンセルを確認する。
9. 権限のないプレイヤーが give/answer/check を実行できないことを確認する。
10. Paperのメニューでページ移動・色変更・Shiftクリック・ドラッグ・数字キーを確認する。

実行できていない項目は「未確認」と記録してください。単にビルドが成功したことを実機確認の代わりにしません。
